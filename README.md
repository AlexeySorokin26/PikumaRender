# 📘 Основные термины компьютерной графики

## 🔹 Линейные преобразования (Linear Transformations)

**Определение:**  
Преобразование T является линейным, если выполняются два свойства:

1. Аддитивность:  
   T(u + v) = T(u) + T(v)

2. Однородность:  
   T(αu) = αT(u)

**Пример — перенос на вектор t:**  
T(v) = v + t

Проверим свойства:

- Аддитивность:  
  T(u + v) = (u + v) + t  
  T(u) + T(v) = (u + t) + (v + t) = u + v + 2t  
  ❌ Не совпадает, значит не линейно.

- Однородность:  
  T(αu) = αu + t  
  αT(u) = α(u + t) = αu + αt  
  ❌ Не совпадает, если t ≠ 0.

**Вывод:**  
Перенос (translation) не является линейным преобразованием, так как изменяет начало координат.

## 🔹 Гомогенные координаты (Homogeneous Coordinates)

**Суть:**  
Точка в N-мерном пространстве представляется как вектор из N+1 компонент.  
Это позволяет представить перенос как линейное преобразование в гомогенном пространстве.

- Для 2D: (x, y, 1)  
- Для 3D: (x, y, z, 1)

**Зачем это нужно:**  
- В обычной 3×3 матрице невозможно задать перенос.  
- В гомогенных координатах (4×4 матрица) — возможно.

## 🔹 World Matrix

**Мировая матрица (World Matrix)** объединяет:

M_world = M_translation * M_rotation * M_scale

Эта матрица преобразует локальные координаты объекта в мировые, располагая 3D-модель в сцене.

---

## 🔹 Projection Matrix (Проекционная матрица)

Проекционная матрица отвечает за:

1. **Aspect Ratio (соотношение сторон):**  
   a = h / w  
   Корректирует масштаб по осям X и Y в зависимости от размеров экрана.

2. **Field of View (угол обзора):**  
   f = 1 / tan(Q / 2)

3. **Normalization (нормализация координат):**  
   Приводит координаты x, y, z к диапазону от -1 до +1 — NDC (Normalized Device Coordinates).

   l = zFar / (zFar - zNear) - (zFar / (zFar - zNear)) * zNear

**Этапы вывода:**
1. Сначала выполняется проекция (projection).  
2. Затем координаты переходят в NDC через подобные треугольники.

# 💡 Освещение (Lighting)

## 🔸 Flat Shading

Цвет треугольника зависит от угла между нормалью поверхности и направлением света.  
Чем ближе нормаль к направлению света, тем ярче цвет.

---

## 🔸 Back Face Culling

Метод отбраковки треугольников, которые повёрнуты от камеры (нормаль направлена в противоположную сторону).  
Используется для оптимизации и ускорения рендеринга.

---

## 🔸 Модель освещения Фонга (Phong Lighting Model)

Общая формула:

I = I_ambient + I_diffuse + I_specular

1. **Ambient (фоновое):**  
   Свет многократно отражается и присутствует везде — даже в тенях.

2. **Diffuse (рассеянное):**  
   I_d = k_d * L_d * (N · L)  
   Чем больше угол между нормалью и источником света, тем ярче пиксель.

3. **Specular (зеркальное):**  
   Отражённый свет, который ярче, когда направление взгляда совпадает с отражением от поверхности.

# 🧵 Текстуры (Textures)

**UV-координаты:**  
Определяют, какая часть текстуры накладывается на поверхность:  
(0, 0) → (1, 1)

---

# 🔹 Барицентрические координаты (Barycentric Coordinates)

Используются для интерполяции значений (цвета, текстуры, нормали) внутри треугольника.  
Позволяют точно определить положение точки внутри треугольника на основе весов его вершин.
